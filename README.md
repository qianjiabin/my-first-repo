# my-first-repo

我的第一个 GitHub 仓库 —— 用来练习 Git 的完整流程。

## 这是什么

这个仓库没有复杂的代码，它是我的**练习场**：把本地文件改动提交上去，再推送到 GitHub，跑通一遍完整流程。

## 学习进度

- [x] 注册 GitHub 账号
- [x] 创建远程仓库
- [x] 把本地文件推送到 GitHub
- [ ] 从 GitHub 克隆别人的项目
- [ ] 给开源项目提交第一个 Pull Request

## 常用命令

```bash
git status                  # 看看有哪些文件改过
git add .                   # 把改动放进暂存区
git commit -m "改了什么"     # 提交到本地
git push                    # 上传到 GitHub
git pull                    # 拉取最新代码
git log --oneline           # 看提交历史
```

## 提交记录

每一次 `git commit` 都会在这里留下痕迹，点仓库页面右上角的提交次数就能看到全部历史。
